# Recursion Maze

- **Sliding Window**
  - A technique that uses a range of consecutive elements `window` that moves across the array to process data efficiently

---

- **Rolling Hash**
  - A technique that computes a `Hash Value` for a strings or numeric sequences and efficiently updates it when elements are added or removed, avoiding full recomputation.

---

- **Backtracking**
  - A recursive technique that explores potential solutions and `backtracks`, undoing previous choices as soon as it determines they cannot lead to a valid result
