# SQL I

The **Keywords** I encountered in this section are:

| **KEYWORD**   | **DEFINITION**                                                                                                |
| :------------ | :------------------------------------------------------------------------------------------------------------ |
| `PRIMARY KEY` | Unique identifier for each **Row** in a **Table**                                                             |
| `LEFT JOIN`   | Returns all **Rows** from the left **Table** and matching **Rows** from the right **Table**, otherwise `NULL` |
