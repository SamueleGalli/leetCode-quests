# SQL II

The **Keywords** i encountered in this section are:

| **KEYWORD** | **DEFINITION** |
| :--- | :--- |
| `MAX()` | Returns the **Maximum Value** from a specified **Expression** |
| `(...) IN (Subquery)` | Checks whether a **Value** or a **List Of Values** *matches* one of the results returned by the **Subquery** |
